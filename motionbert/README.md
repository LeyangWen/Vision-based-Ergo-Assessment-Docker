# MotionBERT

This folder is for the MotionBERT component (2D to 3D pose estimation).

## Setup

Clone MotionBERT repository here:
```bash
git clone https://github.com/Walter0807/MotionBERT.git .
```

## Description

MotionBERT is a unified framework for human motion analysis.
It can be used for 2D-to-3D pose lifting.
